- `3. Taller  MVC CodeIgniter 4 - Parte 1_ Base de Datos, Entorno y Modelos.pdf` → rama `app-v3.0-taller-pqrs-codeigniter`.
- `4. De Archivos JSON a MySQL con Node.js.pdf` → rama `app-v4.0-taller-node`.
- Los dos PDFs `Proyecto PQRS + MYSQL Parte 1...` → rama `app-v5.0-taller-pqrs-node`.

Las partes 2 y 3 de PQRS Node están documentadas en los archivos Markdown públicos del repositorio del instructor enlazados por el usuario.
