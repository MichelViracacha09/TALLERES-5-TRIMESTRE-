# Talleres del quinto trimestre

Repositorio personal para organizar las entregas del quinto trimestre. Cada rama contiene la versión correspondiente al taller; consulta el README de cada rama para requisitos e instalación.

Ramas de entrega:

- `app-v1.0-taller-frontend` — autenticación Front-End.
- `app-v2.0-frontend-componentes` — componentes JavaScript.
- `app-v3.0-taller-pqrs-codeigniter` — PQRS con CodeIgniter 4.
- `app-v4.0-taller-node` — API de productos JSON, SQLite y MySQL.
- `app-v5.0-taller-pqrs-node` — PQRS con Node.js.
